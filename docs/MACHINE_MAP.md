# 机器地图（悬停扫描结果，2026-11-03）

> 方法：`tools/scan_machines.py` —— 在场景里按网格**模拟真人移动**鼠标（分段移动 + 停顿），
> 光标附近像素有变化才跑一次 OCR，把提示文字收下来。
> 一次 84 点扫描约 2 分钟，190 点约 5 分钟（OCR 只在"有提示"时触发，所以比逐点 OCR 快一个数量级）。

复现：

```bash
PYTHONPATH=.pydeps python3 tools/scan_machines.py --travel teleport_cabin --step 110 \
    --x0 200 --x1 2200 --y0 250 --y1 1300 --out data/machines/inventor_room_fine.json
```
