## 0. 方法与坐标系（必读：不读这节会把坐标点反）

### 0.1 视频与抽帧的事实

```
ffprobe artifacts/video/BV1Fu8h6YEAz.mp4
  width=1280 height=720 r_frame_rate=30/1 duration=2447.900000 nb_frames=73437
```

视频文件**存在**（205,124,251 B）。抽帧不是等间隔网格，而是**按章节切段、段内每 7 s 一帧**，
`frames/_ocr.json`（2.67 MB）记录了每帧的 `chapter` / `file` / `ts`（**视频绝对秒**）/ `boxes`，
共 **417 条**，`ts` 从 0.0 到 2447.0，与视频时长吻合。所以**时间戳映射直接查 `_ocr.json`，不需要按 fps 推算**。

三个引用时间戳的实际落点：

| 文档引用 | 秒 | 命中帧 | 该帧实际内容 |
|---|---|---|---|
| 07:08 | 428 | `02_spirit_day1/f_00058.png` | 太空站房间 + 两个辅导员 ✅ |
| 09:58 | 598 | `03_spirit_day2a/f_00015.png` | 太空站房间 + 「已耗尽」提示 ✅ |
| 02:43 | 163 | `02_spirit_day1/f_00020.png`（ts=162） | **「经验分配器」面板** ❌ 不是签到 |

### 0.2 `seerdx ocr` 的 y 轴是**自下而上**的（重要）

实测交叉验证：顶栏聊天条 `•公屏聊天 • 在线` 的 `y=0.9639`，而它是全画面**最上面**一行（y≈8 px）；
底部旁白 `点击之后可以开启8倍经验` 的 `y=0.0083`，而它在**最下面**（y≈690 px）。
结论：

```
y_top/h = 1 - y_ocr - h          （左上角为原点，常规屏幕坐标）
```

**取 box 中心**可以规避这个歧义（中心 = `1 - y_ocr - h/2`，与 y 是上边还是下边无关），
本报告所有可点击坐标一律给**中心点**。

### 0.3 视频分数坐标不能直接搬到真机

视频 **1280×720 = 1.778**；真机截图 **2400×1600 = 1.5**（`docs/state.md`「坐标系」一节已注明宽高比 1.5，
且旧坐标不可按比例缩放）。两者视口不同，**分数坐标不能平移复用**，必须**用文本锚点重新投影**。
1.4 节给的"可移植规则"就是为此设计的。
