### 2.2 执行过程（Goal Runner，非脚本）

```bash
python3 -m seerauto goal start puni --planner deterministic --allow-input \
    --max-minutes 26 --max-battles 32
```

一次运行里发生的事（都可在 `data/goalrunner.sqlite3` 的 `events` 表里查到）：

1. **观测**：抓帧 → 场景判定 `WORLD`（LIVE_VERIFIED）→ 窗口几何 (270,87) 1200×800；
2. **preflight**：尝试读精灵等级；精灵面板被残留的「恭喜你得到了53个积累经验」弹窗挡住 →
   如实记下 `preflight pet read failed`，**没有编造等级**；
3. **规划**：`puni.prepare.level_up`，理由与期望观测写入 `node.selected` 事件；
4. **执行**：`game.navigate_spt_boss(蘑菇怪)` → SPT 面板 OCR 定位「前往」→ 传送成功 →
   `game.run_battle(battles=10)` 连战；
5. **暂停/恢复**：`goal pause` 生效（状态转 `pause-requested`，暂停期间无点击），
   `rm /tmp/seerauto.pause` 后继续；
6. **验证**：每场战斗用胜利面板「消失」判定，而不是"点了确认就算赢"。
