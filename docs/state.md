- 打开方式：点机器 → 选精灵 → 确认 → 进入技能面板。

- **点左边一个 + 点右边一个 → 确认**，花 **100 赛尔豆** 换一次。
- 本次把 瞪眼(威力0) 换成 **火焰车(威力95)**，并验证提示「你花费了100赛尔豆使烈火猴技能唤醒成」。
