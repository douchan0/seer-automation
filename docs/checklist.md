## Phase 1 · 第一天：从 0 到三只打架主力（00:29–08:34）

### 基础资源
- [ ] 每日签到领奖励
- [ ] 领超能 NoNo 三枚芯片（飞行 / 元神赋形 / 超能训练）
- [ ] 露西欧星刷"露西之核"，凑齐三种材料
- [ ] 用芯片制造机合成 → 开启飞行模式
- [ ] 每天找 50 级野怪（杰拉特）开战**直接逃跑**，白嫖 50 万经验（每天仅 1 次）
- [ ] 打一次钢牙鲨，攒经验池（约 200 万）
- [ ] 去精灵太空站找辅导员开「8 倍经验 / 4 倍学习力」

### 精灵
- [ ] 小火猴练到 36 级 → 进化**烈焰猩猩**
- [ ] 克洛斯星抓 **皮皮** → 养成 **比波**（保留「手下留情」）
- [ ] 火山星抓 **吉尔**（Lv17，随便挑一只）
- [ ] 融合转生仓：烈焰猩猩 + 吉尔 → 红色元神珠
- [ ] 元神赋形 → **炎火猴**，灌经验到 100 级 → **魔焰猩猩**
- [ ] 魔焰猩猩换上「**绝命火焰**」（威力 100，秒杀杂兵神技）
- [ ] 交易行/商城买 **萨拉**：性格筛「沉着」、个体筛「31」、价格由低到高，约 5W
- [ ] 萨拉练到 72 级 → 进化 **萨帕克（仙女龙）** → 拉到 100 级
- [ ] 萨帕克刷满学习力：**特防 + 速度**（训练室一次 +4）
- [ ] 商城买 **闪光尼尔**，挑「**瞬杀**」特性（备用）
- [ ] 交易行买 **闪光皮皮**：只要高个体 + 加速性格，约 1.4W
- [ ] 闪光皮皮养到 99 级 → **闪光波克尔**，速度刷满，**必带「同生共死」**
- [ ] 交易行买 **卡西达**（个体越高越好，约 5.6W）→ 养成 **卡奥鲁**，攻击+速度
- [ ] SPT 打 **哈莫雷特**（卡兰星系 尼古尔星/塔克星）
- [ ] 哈莫雷特配招：龙之意志 / 回避 / 龙王波 / 龙王灭碎阵，刷攻击+特防
- [ ] SPT 走**龙王殿**拿到 **塞维尔**（精元孵化）
- [ ] 塞维尔刷特防+体力，配招：锁敌 / 龙之毒 / 龙女之声 / 重踏
- [ ] SPT 打 **纳多雷**（双子阿尔法星-阿尔法星岩地）→ 孵化
- [ ] 纳多雷刷特防+体力，配招：属性反转 / 地裂 / 地之守护
- [ ] 勇者之塔推到高层（奖励赛尔豆）
- [ ] 试炼之塔推到高层

## Phase 2 · 第二天：补齐阵容 + 备药（08:34–11:16）

- [ ] 先"送一遍海盗"拿每日 50 万经验
- [ ] 再核对一遍 7 只精灵的面板与配招是否都对
- [ ] 开 8 倍经验，把卡奥鲁/闪光波克尔/塞维尔都拉到 99–100 级
- [ ] 商店买 **高级体力药剂 ×100**
- [ ] 备足 **超级体力药剂**（回 150）、**高级活力药剂**（补 20 次 PP）← 刚需
- [ ] 备足 **高级活力药剂**，谱尼战会用到几十瓶
- [ ] 确认「每天最多打 4 个封印」

- [ ] **七彩龙息**输出收掉
- [ ] 血低了吃超级体力药剂（回 150）

### 封印 2 · 元素 / 封印 3 · 能量（12:58，打法相同，一天内连打）

- [ ] 找机会用**龙王波**（必中）打血
- [ ] PP 快空时吃**高级活力药剂**补

### 封印 4 · 生命（15:04）

## Phase 3 · 第三天：最后两只精灵（16:34–19:16）

- [ ] 收下昨天孵化的 **塞维尔**（100 级），确认性格是「任意+特防」
- [ ] 性格不对就去商城买 **尼尔**（个体 28 左右即可，约 3W）
- [ ] 拿塞维尔 + 尼尔 做**基因重组**洗性格
- [ ] 重组时用**元神珠极速孵化药剂**省时间
- [ ] 打 SPT 拿 **纳多雷** 并孵化（不挑个体性格）
- [ ] 野外抓 **克里**：要求**低个体 + 不加特防性格**（用闪光波克尔同生共死削血后丢胶囊）
- [ ] 克里升到 54 级 → 花 **100 赛尔豆**技能唤醒「**偏激防守**」
- [ ] 用**精灵还原药剂**把克罗达还原成 **1 级**
- [ ] 确认还原后**特防 = 6**（显示 7 就重洗）
- [ ] 克罗达技能组：快攻 / 漩涡 / 偏激防守 / 意念集中

### 封印 5 · 轮回（19:52，4 条命，最难）

- [ ] 哈莫**龙之意志 + 回避**耗 PP
- [ ] 纳多雷**属性反转** → **地裂**慢慢补
- [ ] 塞维尔**龙之毒**上毒，挂完就可以送
- [ ] 闪光波克尔**同生共死**
- [ ] 哈莫**龙王灭碎阵**输出
- [ ] 第 2 条：**塞维尔毒 + 同生共死**

## Phase 4 · 谱尼真身 S 级（27:51，约 15–25 分钟）

### 开打前
- [ ] 7 只全部带齐，确认克罗达是 **Lv1 / 特防 6**
- [ ] 确认塞维尔带**锁敌**（龙之毒只有 50% 命中）
- [ ] 开 2 倍速，准备好体力 + 活力药剂
- [ ] 记住：谱尼放「圣光气」= 它这招没 PP 了，是最软的输出窗口

### 第一命（虚无）
- [ ] 萨帕克**精神强化 + 感应**轮流叠（先感应保命）
- [ ] **七彩龙息**暴击收掉

### 第二命（元素）
- [ ] 萨帕克先随便打点血
- [ ] 换塞维尔：**锁敌 → 龙之毒** 反复挂毒
- [ ] 毒到死

### 第三命（能量）
- [ ] 萨帕克上**感应**，**耗光谱尼 5 个圣灵魔闪光**
- [ ] 之后**全程相位移动**躲千烈虚光闪/旋灭裂空阵（约 20 次）
- [ ] 等谱尼开始连续放**圣光气**（= PP 空）
- [ ] 塞维尔过渡一下
- [ ] 换**克罗达**：**意念集中 ×2** → **漩涡点 7 下**冻死

### 第四命（生命）
- [ ] 克罗达**偏激防守**弹伤 → 谱尼被反弹死
- [ ] **快攻**收尾
- [ ] 换卡奥鲁**极烈暴风掌**过渡

### 第五命（轮回，4 条命）
- [ ] 萨帕克**感应**扛 → **相位移动**耗光千烈虚光闪
- [ ] 纳多雷**属性反转** → **地裂**磨
- [ ] 闪光波克尔**同生共死**拉平血量
- [ ] 卡奥鲁补刀
- [ ] 塞维尔**锁敌 → 龙之毒**
- [ ] **中毒剩 1 回合时立刻换萨帕克提前接毒** ← 最关键的细节
- [ ] 剩下几条命循环"塞维尔丢毒提速 + 仙女龙补掉"

### 第六命
- [ ] 塞维尔 **重踏 → 龙之毒** 循环
- [ ] 用**初级活力药剂**补技能次数
